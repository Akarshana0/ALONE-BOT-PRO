// Step by Step

How to Connect

01
Setup MongoDB Atlas
Create a free MongoDB Atlas cluster. Copy your connection string and set it as MONGODB_URI in your .env file.
MONGODB_URI=mongodb+srv://...
02
Configure Your Number
Set your WhatsApp number (with country code, digits only) as OWNER_NUMBER and PAIR_NUMBER in .env.
OWNER_NUMBER=94714768679
03
Start the Bot
Run npm start. The bot connects to MongoDB, loads all commands, then generates a pairing code in the terminal.
npm start
04
Link WhatsApp
On your phone: WhatsApp → Linked Devices → Link a Device → Link with phone number → Enter the pairing code.
XXXX-XXXX ← enter in WhatsApp
05
You're Live! 🎉
The bot sends you a welcome message. Type .menu to see all commands. Enjoy 268 features!
.menu
